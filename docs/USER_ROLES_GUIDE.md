## 1. System Administrator (`admin@school.edu`)
- **Key Responsibilities:** Oversee user accounts, adjust system settings, manage institutional permissions, and audit security events.
- **Workflow:** Navigate to Admin Hub to review provisioned accounts, create new faculty/student profiles, or inspect the live audit trail of logins, updates, and deletions.

## 2. Headmaster (`headmaster@school.edu`)
- **Key Responsibilities:** Strategic institutional governance, academic health, fiscal standing, and executive approvals.
- **Workflow:** Review enrollment KPIs, track fee collection percentages, monitor faculty-to-student ratios, and endorse final exam results.

## 3. Academic Officer (`academic@school.edu`)
- **Key Responsibilities:** Curriculum architecture, academic year calendars, terms, and subject accredited offerings.
- **Workflow:** Add classes, configure streams (East/West/North), specify core vs elective subjects, and allocate teaching weeks.

## 4. Teacher (`teacher@school.edu`)
- **Key Responsibilities:** Classroom instruction, roll call, student marks entry, and assignment coordination.
- **Workflow:** Open Roll Call Register, choose class and date, mark student presence (Present, Absent, Late), and save the daily register with one click.

## 5. Student (`student@school.edu`)
- **Key Responsibilities:** Academic learning, assignment completion, library reading.
- **Workflow:** View daily class timetable, check term examination report cards, monitor tuition balance, and inspect borrowed library books.

## 6. Parent (`parent@school.edu`)
- **Key Responsibilities:** Monitoring student ward attendance, verifying performance, settling tuition invoices.
- **Workflow:** Open Parent Portal to review child's GPA, view itemized term fee statements, and simulate instant digital fee remittance.

## 7. Bursar / Accountant (`accountant@school.edu`)
- **Key Responsibilities:** Fee structure schedules, bulk term billing, payment receipts, financial telemetry.
- **Workflow:** Execute Batch Invoicing for enrolled cohorts, track unpaid vs paid invoices, and issue official financial receipts.

## 8. Librarian (`librarian@school.edu`)
- **Key Responsibilities:** Catalog maintenance, loan checkout, returns inspection, and overdue fine management.
- **Workflow:** Check out books to student admission numbers, record book returns to restock shelves, and track overdue loan fines.

## 9. Examination Officer (`exam@school.edu`)
- **Key Responsibilities:** Exam scheduling, invigilation rosters, grading scale benchmarks, official transcripts.
- **Workflow:** Schedule exam papers, assign halls and invigilators, verify marks moderation, and batch-print official report cards.

## 10. Staff (`staff@school.edu`)
- **Key Responsibilities:** Campus communications, bulletin broadcasting, visitor check-in.
- **Workflow:** Draft campus notices with priority tags, monitor visitor gate passes, and resolve administrative queries.
